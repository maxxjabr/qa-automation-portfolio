# QA Automation Portfolio

## Week 1: Test Quotes Site

This project uses Selenium and Pytest to automate tests on http://quotes.toscrape.com.

### Setup

1. Clone the repo
2. Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install dependencies:

```bash
pip install -r requirements.txt
```

### Run tests:

```bash
pytest
```
